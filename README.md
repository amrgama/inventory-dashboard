# 📦 Inventory Dashboard

A full-stack inventory management dashboard built with NestJS, MongoDB, and React (Vite + Redux Toolkit).

---

## ⚙️ Tech Stack

### Backend
- NestJS (TypeScript)
- MongoDB + Mongoose
- Docker

### Frontend
- React + Vite (TypeScript)
- Redux Toolkit
- Mantine UI
